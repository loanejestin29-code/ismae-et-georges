# Ismae et Georges

Page d'accueil de l'app *Ismae et Georges*, une petite aventure en pixel art dans les rues de Paris.

Site statique en HTML, CSS et JavaScript, sans dépendance ni étape de build :

- `index.html` : la page
- `style.css` : les styles
- `script.js` : Georges, le chat noir, dessiné pixel par pixel

## Hébergement sur Vercel

Importer ce dépôt dans Vercel avec le préréglage **Other**. Aucune commande de build, dossier de
sortie : la racine du dépôt.

## Voir la page en local

Ouvrir `index.html` dans un navigateur.
